# '24~'26년 우주사업부 퇴직 현황 및 원인 분석

## 1. 개요
- 분석 배경
  - 우주사업부 내 우주연구소 중심의 퇴직 증가 우려가 대두되어, 퇴직률 및 원인을 확인하고자 함
- 분석 기간 : '24~'25년 연간, '26년 1~9월
- 분석 요인 : ① 사업장 ② 인력 구성 ③ 외부 요인 ④ 조직·업무 환경

## 2. 분석 결과 요약
(분석 후 작성 : 4~8장의 → 결론을 모아 작성)

## 3. 시사점
(분석 후 작성)

## 4. 퇴직 현황
- 사업부별 자발적 퇴직률 추이(4개 사업부 및 전사)
  - [표] 행: 4개 사업부·전사 / 열: '24 · '25 · '26(1~9월)
  - → 우주사업부 퇴직률 ○○

## 5. 사업장 요인 ①
- 사업부×사업장별 퇴직률(우주·DE / 용인·용인 외)
  - [표] 2×2 ('26년 1~9월 기준, 칸이 작으면 '25년 추가)
  - → 사업장 위치 ○○

## 6. 인력 구성 요인 ②
- 사업부별 재직자 근속 분포 및 근속 구간별 퇴직률(5년 미만 / 이상)
  - [표] 1개
  - → 저연차 ○○

## 7. 외부 요인 ③
- 퇴직 사유별 비중(전직·학업·가사 등) 및 전직처 분포
  - [표] 사유별 / 전직처별
  - → 타 산업 이동 성격 ○○

## 8. 조직·업무 환경 요인 ④
- 우주사업부 부서별 퇴직 현황('24~'26)
  - [표] 1개
- 퇴직자 면담 등 정성 의견 (실명 제외)
  - → 우주 고유의 조직·업무 환경 요인 ○○

- 기준인원은 기간 말 재직자 기준으로 통일 ('24·'25: 12월 말, '26: 9월 말)
